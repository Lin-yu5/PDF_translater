# 學術論文與文獻翻譯 Skills 規則 (Academic Paper Translation Rules)

本規則專為學術期刊、研討會論文、教科書章節與研究報告之翻譯設計。

## 1. 論文架構與章節規範
- 章節標題保留標準格式：
  - Abstract -> 摘要
  - Introduction -> 引言 / 前言
  - Methods / Methodology -> 研究方法
  - Results -> 研究結果
  - Discussion -> 討論
  - Conclusion -> 結論
  - References / Bibliography -> 參考文獻（內容不予翻譯，保持原引用格式）

## 2. 引用與參照保護 (Citations & Cross-References)
- **文獻引用標籤絕對不變**：如 `[1]`, `[2, 3]`, `[4-7]`, `(Smith et al., 2021)`, `Case-Smith (2020)` 必須完整保留。
- **圖表跨章參照**：
  - `Fig. 1`, `Figure 2.3` 譯為 `圖 1`、`圖 2.3`（或保留原英文）。
  - `Table 1`, `BOX 29.2` 譯為 `表 1`、`焦點方塊 29.2`。
- **標識碼保留**：DOI (如 `doi:10.1016/...`)、ISBN、ISSN、網址 URL 一律完全保留。

## 3. 統計數值與研究指標 (Statistical Notations)
- 統計符號完全保留大小寫與斜體特性：
  - `p < 0.05`, `p = 0.001`
  - `95% CI` (95% 信賴區間)
  - `OR`, `RR`, `HR` (勝算比、相對風險、風險比)
  - `SD`, `SE`, `M` (標準差、標準誤、平均數)
  - `ANOVA`, `t-test`, `chi-square (χ²)`

## 4. 排版與標點
- 學術繁體中文統一使用全形標點（，。；：「」『』）。
- 括號內為純英文或純數字時可使用半形括號 `()`，全中文時使用全形括號 `（）`。
- 專利號、試驗編號（如 NCT01234567）原樣保留。
