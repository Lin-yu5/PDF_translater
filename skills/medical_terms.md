# 醫學與臨床專業翻譯 Skills 規則 (Medical & Clinical Translation Rules)

本規則專為醫學、臨床、職能治療 (OT)、物理治療 (PT)、神經學及病理學相關文獻翻譯設計。

## 1. 專有名詞與縮寫規範 (Medical Abbreviations)
以下核心醫學縮寫在繁體中文語境下通常直接保留原文，或使用標準繁體醫學譯名：
- **CP**: 腦性麻痺 (Cerebral Palsy)
- **GMFCS**: 粗大動作功能分類系統 (Gross Motor Function Classification System)
- **MACS**: 手部操作能力分類系統 (Manual Ability Classification System)
- **CFCS**: 溝通功能分類系統 (Communication Function Classification System)
- **EDACS**: 進食與飲水能力分類系統 (Eating and Drinking Ability Classification System)
- **ROM**: 關節活動度 (Range of Motion)
- **PROM / AROM**: 被動 / 主動關節活動度
- **ADL / IADL**: 日常生活活動 (Activities of Daily Living) / 工具性日常生活活動
- **PT / OT / ST**: 物理治療 / 職能治療 / 語言治療
- **CT / MRI / fMRI / EEG / EMG**: 電腦斷層 / 磁振造影 / 功能性磁振造影 / 腦電圖 / 肌電圖
- **MAS**: 改良式艾許沃斯量表 (Modified Ashworth Scale)
- **PEDI**: 兒童身心障礙評估量表 (Pediatric Evaluation of Disability Inventory)
- **BOT-2**: 布魯茵克斯－奧西瑞斯基動作精熟度測驗
- **CIMT**: 限制－誘發動作療法 (Constraint-Induced Movement Therapy)
- **NDT**: 神經發展治療 (Neurodevelopmental Treatment / Bobath approach)

## 2. 繁體中文醫學術語對應表 (Medical Terminology Conventions)
- Spastic / Spasticity: 痙攣型 / 痙攣
- Dyskinetic / Dyskinesia: 動作障礙型 / 不隨意動作
- Ataxic / Ataxia: 運動失調型 / 運動失調
- Hypotonia / Hypertonia: 低肌張力 / 高肌張力
- Diplegia / Hemiplegia / Quadriplegia: 雙邊麻痺 / 偏癱（半身麻痺）/ 四肢麻痺
- Monoplegia / Triplegia: 單肢麻痺 / 三肢麻痺
- Co-contraction: 共同收縮
- Postural tone / Postural control: 姿勢張力 / 姿勢控制
- Contracture: 關節攣縮
- Deformity: 變形 / 畸形
- Orthosis / Splint: 矯具（副木）
- Assistive Technology: 輔助科技（輔具）
- Sensation / Proprioception: 感覺 / 本體感覺
- Vestibular: 前庭覺

## 3. 藥物與處置規範 (Drugs & Interventions)
- 藥物名保留原英文並標註通用譯名（例如：Baclofen（巴氯芬）、Botulinum toxin A（肉毒桿菌素A型））。
- 外科手術保留國際醫學全名（例如：SDR (Selective Dorsal Rhizotomy, 選擇性背神經根切斷術)）。

## 4. 嚴格輸出要求
- 保留所有 ICD 疾病編碼、計量單位（mg/kg, Hz, dB 等）。
- 嚴禁添加任何譯者註解或解釋性贅詞。
